# Prompt Spelling and Terminology Handling Rule

When interpreting and processing user prompts in Antigravity IDE:
1. **Intelligent Typo Resolution**: Automatically identify and resolve typographical errors, phonetic spellings, or transposed characters in user prompts (e.g., "distulation colom" -> "distillation column", "slivers" -> "sliders", "decription" -> "description", "githup" -> "github").
2. **Context-Aware Mapping**: Map informal or misspelled industrial instrumentation / process control terms (such as "deadtime", "timeconstant", "quarter amplitude", "reset rate") to their precise engineering standards and code identifiers.
3. **Seamless Execution**: Act upon the corrected intent immediately without interrupting the user or blocking execution for minor spelling errors. In your response, use the correct technical terms naturally.
